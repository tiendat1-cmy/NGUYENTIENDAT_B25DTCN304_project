# Cinema Management System

## Overview

**Cinema Management System** is a software project designed to support cinema operations and movie ticket booking.

The system aims to provide a convenient way for customers to explore movies, view showtimes, select seats, and manage their bookings, while helping administrators manage cinema-related information.

## Main Features

The project is intended to cover the following areas:

### Customer Features
- Browse available movies.
- View movie details and information.
- Check movie showtimes.
- Select seats for a screening.
- Book movie tickets.
- View booking information.

### Administration Features
- Manage movie information.
- Manage cinema rooms.
- Manage screening schedules.
- Manage seat information.
- Manage ticket bookings.
- Manage customer information.
